# Projects

Each project should contain:

- `README.md` — requirements, architecture, setup, and usage
- `DECISIONS.md` — important design decisions and tradeoffs
- `EVALUATION.md` — test cases, metrics, and results
- `src/` — implementation
- `tests/` — deterministic and scenario tests
