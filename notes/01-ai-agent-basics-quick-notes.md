# AI Agent Basics — Quick Notes

**AI Agent = Model + Instructions + State + Tools + Control Loop + Environment + Memory + Safety + Evaluation**

### Model

The **brain/intelligence** of the AI.
It learns patterns from data and generates predictions, decisions, or responses.

### Instructions

Tell the AI **what to do and how to behave**.
Example: “Summarize this article in 3 bullet points.”

### State

The information the AI is working with **right now**.
Example: current conversation, current task, recent tool results.

### Tools

External capabilities the AI can use.
Examples: web search, calculator, email, APIs, databases, file readers.

### Control Loop

The repeated process the agent follows:

**Observe → Think → Act → Observe → Repeat**

It continues until the task is complete.

### Environment

The **outside world** the agent interacts with.
Examples: users, websites, files, apps, databases, physical surroundings.

### Memory

Information saved so the AI can **use it later**.

**State = current information**
**Memory = retained information**

### Safety

Rules and protections that prevent harmful, unsafe, private, or unauthorized actions.

### Evaluation

Checks **how well the AI performed**.

It can measure:

* correctness
* instruction following
* tool usage
* safety
* efficiency
* task success

## Easy Analogy

**Model** = Brain
**Instructions** = Mission
**State** = Current awareness
**Tools** = Hands
**Control Loop** = Think-and-act cycle
**Environment** = World
**Memory** = Past information
**Safety** = Guardrails
**Evaluation** = Performance check

### Final Idea

When all these components work together, they form an **AI Agent / Agentic AI System**.
